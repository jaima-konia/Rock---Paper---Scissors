# Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using HTML, CSS, and JavaScript.

The player chooses Rock, Paper, or Scissors, and the computer randomly selects it's choice. The game then determines the winner and keeps track of the score.

## 🎮 Live Demo

[View Live Demo][(https://your-live-demo-link.com](https://jaima-konia.github.io/Rock---Paper---Scissors/))


## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Math & Randomization

## ✨ Features

- Play Rock, Paper, Scissors against the computer
- Computer makes a random choice
- Displays the player's and computer's choices
- Automatically determines the winner
- Keeps track of the score
